REIGN OF DOOM — ALPHA 2.1 / MOBILE-FIRST ARCADE RECOVERY

Current packages:
  reign-of-doom-alpha21-browser.zip — ready-built game and static server
  reign-of-doom-alpha21-complete.zip — built game, source, tests and report

Extract and run: node scripts/serve.mjs
For iPad on the same Wi-Fi, set HOST=0.0.0.0 before running the server,
then open the printed tablet address. Node 24 recommended. No npm install
is required for built output. Gameplay makes no network requests after loading.
Reloading requires the server again. Do not double-click index.html.

Two players starts a shared-screen game. Drag pieces and soldiers. Pull the
ballista ring to fire. Two fingers move/zoom. Ready advances early.

Chromium tablet/touch tests are recorded. Actual iPad Safari/hardware remains
unverified; the WebKit download was blocked by the environment's network policy.
Read the complete report before treating iPad compatibility as established.

Older Alpha 1/2 packages are retained as historical releases.
